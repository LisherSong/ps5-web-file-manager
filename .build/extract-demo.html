ZIP 解压功能演示

PS5 Web File Manager · 首版仅支持未加密、未分卷普通 ZIP（stored / deflate / ZIP64），拒绝符号链接/设备文件/FIFO。

两种入口 · 一种安全策略

1解压到当前目录

选中已存在的 .zip → 工具栏出现青绿 解压 按钮 → 选冲突策略 → 进度条走完

2上传并解压

从浏览器拖入 .zip → 上传完成弹出"解压到当前目录？" → 可选解压后删除源

3三种冲突策略

fail(默认·安全) / overwrite(覆盖) / merge(合并目录)

接下来你可以直接解压它。

解压前ZIP 内容已先扫描 CRC + 文件大小，确认不是分卷/加密/SPD才进解压。
解压时不存在的父目录会自动创建，已存在的普通文件按你选的冲突策略处理。

当目标目录里已经存在某些待解压的文件或目录时，三种冲突策略的行为差异。

情景 fail（默认） overwrite merge
目标不存在 / 是空目录 ✓ 直接成功 ✓ 直接成功 ✓ 直接成功
ZIP 内是 a.txt，目标已有 a.txt（普通文件） ✗ 失败回滚
err_extract_conflict		 ⚠ 覆盖
CRC 校验后写入		 ✗ 失败回滚
merge 仅处理目录
ZIP 内是 sub/，目标已有 sub/（目录） ✓ 递归合并
子级再按规则		 ✓ 递归合并 ✓ 递归合并
ZIP 内是 a.txt，目标已有 a.txt 但它是符号链接 ✗ 拒绝写入
err_extract_special_entry		 ✗ 拒绝写入 ✗ 拒绝写入
ZIP 内含 符号链接条项（如 lib → /mnt/...） ✗ 拒绝条目
err_extract_special_entry		 ✗ 拒绝条目 ✗ 拒绝条目
ZIP 内含巨型单文件（>8 GiB）或炸弹（解压比>100） ✗ 拒绝

冲突策略不绕过 size 限		 ⚠ 需显式 large=1

💡 推荐用法：日常解压用默认 fail，需要"补丁式更新"已有目录时用 merge，只有确信要"以新覆盖旧"时才用 overwrite。
